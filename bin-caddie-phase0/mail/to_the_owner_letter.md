# Letter: "To the Owner" (properties approved for short-term accommodation)

**Who gets it:** addresses in Workbook → *Council DA Targets* where `signal = short_term_accommodation` and `pitch = To the Owner letter`. That's about 200 properties.

**Rules:**
- Address it to **"The Owner"** and the street address. Never use a name, even if you saw one in the council record.
- Send it by Australia Post addressed mail, or hand-deliver it on a run if there's no "No Junk Mail" sign.
- Log the date in the *letter sent* column.
- **Start with the 50 most recent approvals.** Newer approvals are more likely to be operating and less likely to have a bin arrangement yet.

**Tracking:** print the QR code from `drop_plan.csv` with campaign `p0_owner`, or use the URL below, and use the quote code **OWN1**.
